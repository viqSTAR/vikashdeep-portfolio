# Vikashdeep Prasad Portfolio

A dependency-free, responsive portfolio site focused on healthcare software, AI products, business systems, and Unreal Engine C++ development.

## Run locally

Open `index.html` in a browser, or use a static server:

```powershell
npx serve .
```

## Before publishing

- Replace or add direct links only after verifying the destination is live.
- Add screenshots or a short demo video for the private/client projects.
- Publish this folder as a new GitHub repository, then deploy it with GitHub Pages, Vercel, or Netlify.
- Keep the project descriptions factual; do not add client names, private data, or unsupported metrics.
- The site includes a permission-request notice for public-source reuse. Add an explicit `LICENSE` file to each repository before relying on that policy.
